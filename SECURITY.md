# Security

## Current scope

Universal IR has no released compiler or runtime. Security reports can still concern the development tooling, GitHub workflows, dependency handling, or a concrete flaw in the proposed capability model.

## Report privately

Use [private vulnerability reporting](https://github.com/1xmint/universal-ir/security/advisories/new). Describe the affected revision, the problem, its impact, and safe reproduction steps. Do not include working credentials, personal data, or secrets.

Ordinary documentation problems and non-sensitive design proposals belong in public issues. Please keep undisclosed vulnerabilities out of public issues and pull requests until the maintainer has assessed them.

## Maintenance

The maintainer is @1xmint. There is no published response-time commitment or supported release series yet. A supported-version policy and release security checks must be established before the first runtime release.

Contributors and agents should keep provider credentials in their existing tool's authentication store or local environment. Documentation checks require no model credentials and make no model calls.
